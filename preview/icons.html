How to Use in Shopify Liquid

Basic usage in a Liquid file:

{% comment %} Render an icon {% endcomment %}
{% render 'icon',
  name: 'cart',
  size: 24
%}

With custom size and class:

{% comment %} Custom size + class {% endcomment %}
{% render 'icon',
  name: 'search',
  size: 20,
  class: 'header-icon'
%}
